이건 기계학습일까? 어떤 학습일까?

Ⅱ-01 · Ⅱ-036분
공책에 번호마다 지(지도) · 비(비지도) · 강(강화) · X(기계학습 아님) 중 하나를 적어요.«셋, 둘, 하나» 하면 손가락으로 동시에 — 지 1 · 비 2 · 강 3 · X 주먹
1지난 2년 급식 기록으로 내일 잔반량(kg)을 맞힌다
지도 — 예측(숫자)
2도서관 대출 기록으로 독서 성향이 비슷한 학생끼리 묶는다(묶음 이름은 없음)
비지도 — 군집
3출석부를 번호 순서대로 정렬한다
X — 절차가 분명한 규칙(정렬)
4손으로 쓴 숫자 사진에 0~9 정답을 붙여 학습해 새 사진을 알아본다
지도 — 분류
5로봇 청소기가 부딪히면 점수를 잃고 구석까지 닦으면 점수를 얻으며 길을 배운다
강화 — 보상
6게시판에 같은 글을 10번 넘게 올리면 자동으로 막도록 선생님이 정해 둔다
X — 사람이 정한 규칙
정리 — 기계학습은 사람이 규칙을 짜는 대신 데이터에서 규칙을 찾는 것. 정답이 있으면 지도(분류 = 종류 · 예측 = 숫자), 정답 없이 묶으면 비지도(군집), 보상으로 행동을 배우면 강화.

📜 대본 · 5–11′ (D반 12–16′ · 카드 1 · 2 · 5만)

여섯 개를 보고 공책에 지, 비, 강, 아니면 X를 적어요. 30초. … 짝이랑 맞춰 봐요. … 셋, 둘, 하나!
  • 카드마다 손가락 확인 → «답 보기»로 하나씩. 갈린 카드는 «왜 그렇게 생각했어?» 한 명씩.
  • 예상 오답: 6번을 지도로 고름 → «정답 데이터에서 배웠나, 선생님이 숫자 10을 정했나?» / 2번을 지도로 → «‹소설파› 같은 이름을 미리 줬나?» / 1번을 분류로 → «답이 kg 숫자면?»
  • 마지막 정리 상자를 함께 읽기. «분류 = 종류, 예측 = 숫자»를 소리 내어.

📜 대본 · 11–15′ (D반 16–19′)

좋은 데이터의 네 기준, 기억나는 사람? … 정확성, 관련성, 시의성, 다양성. 네 카드가 하나씩 어긋났어요. 30초 동안 짝지어 봐요.
  • (가)를 «다양성»으로 고르는 학생이 많아요 → «여러 상황이 부족한가, 값이 틀렸나?»
  • 함정 상자: 시험에 «무조건 최신»이 자주 나온다는 말은 하지 않고, «알맞은 시기»로만 강조.
  • 편향 두 가지(교과서 66쪽 결): 현실의 편향 반영 · 잘못 뽑은 표본 — 한 줄씩만.

k-최근접 이웃 — k가 바뀌면 답도 바뀐다

Ⅱ-04 · 분류7분
● 고양이 · △ 강아지 · □ 새 동물 X(5, 3) · 거리는 두 점 사이 직선 거리
X와 가까운 순서대로 이웃을 세어 다수결. k = 1, 3, 5일 때 X는?
k가까운 이웃결과
1A(1)● 고양이
3A · B(√2 ≈ 1.4) · C(2)△ 강아지 (2 : 1)
5+ D(√5 ≈ 2.2) · E(√10 ≈ 3.2)△ 강아지 (3 : 2)
거리 = √(가로 차² + 세로 차²). X–B: √(1² + 1²) = √2 · X–D: √(2² + 1²) = √5. k를 바꾸면 결과가 바뀔 수 있어요.

📜 대본 · 15–22′ (D반 19–25′)

새 동물 X가 들어왔어요. 고양이일까요, 강아지일까요? 가장 가까운 이웃 k마리에게 물어봐서 많은 쪽으로 정하는 게 k-최근접 이웃이에요. 먼저 k = 1, 제일 가까운 한 마리는?
  • 시범: k = 1은 선생님이(A, 바로 위 1칸). 원 하나 보여 주기(답 보기 ①).
  • 학생: k = 3, 5는 30초 혼자 → 짝. 거리를 손으로 구하게: X–B 대각선 √2, X–C 왼쪽 2칸.
  • 예상 오답: k = 5에서 G를 넣음 → «G까지 거리는? √18 ≈ 4.2 · E는 √10 ≈ 3.2» / F(√13 ≈ 3.6)와 E 순서 헷갈림.
  • 마무리 한 줄: «k가 작으면 바로 옆 하나에 휘둘리고, k를 바꾸면 결과가 달라질 수 있다.»

k-평균 — 할당하고, 평균으로 옮기고, 멈출 때까지

Ⅱ-04 · 군집(비지도)9분
데이터 1, 2, 6, 7, 8, 15 를 k = 2로 묶어요. 처음 두 중심은 1과 2.① 각 값을 더 가까운 중심에 할당 → ② 중심을 그 묶음의 평균으로 옮기기 → 중심이 안 바뀔 때까지 되풀이
단계중심묶음 1묶음 2새 중심(평균)
1번째1 · 212, 6, 7, 8, 151 · 38 ÷ 5 = 7.6
2번째1 · 7.61, 26, 7, 8, 151.5 · 36 ÷ 4 = 9
3번째1.5 · 91, 26, 7, 8, 151.5 · 9 → 그대로 = 멈춤
2번째에 2가 묶음을 옮겨요 — 2와 1 사이 거리 1, 2와 7.6 사이 거리 5.6. 중심이 더 이상 안 바뀌면 끝(수렴): 1.5와 9.

📜 대본 · 22–31′ (D반 25–33′)

k-평균은 정답이 없어요. 그냥 가까운 것끼리 두 묶음으로 나눠요. 순서는 딱 두 개 — 할당, 평균. 첫 줄은 선생님이 할게요.
  • 시범(1번째 줄): 1은 중심 1에, 2부터는 중심 2가 더 가까움 → 평균 1과 7.6. 칠판에 수직선 그리기.
  • 학생(2 · 3번째 줄): 1분 혼자 → 짝. «2는 어느 중심이 더 가까워졌지?»를 꼭 묻기.
  • 예상 오답: 새 중심을 «가운데 값»으로(중앙값 7.5 등) → «평균 = 다 더해서 개수로 나누기» / 1번째에서 바로 멈춤.
  • 마무리: «k-평균 = 비지도 · 군집, k-최근접 이웃 = 지도 · 분류 — 이름이 비슷해도 다른 것.»

로지스틱 회귀는 이름은 «회귀»지만 분류에 써요(확률 → 기준값). 선형 회귀는 예측(숫자) — 직선 y = ax + b로 예측하고, MSE가 작은 직선이 더 잘 맞아요.

📜 대본 · 31–38′ (D반 33–39′)

로지스틱 회귀는 «성공할 확률 0.72»처럼 확률을 줘요. 그걸 몇부터 성공으로 볼지, 그 기준값은 우리가 정해요.
  • ① 30초 → 손가락으로 명 수. 0.5 → 3명, 0.6 → 2명. «기준을 올리면 1로 보는 사람이 많아질까 적어질까?»
  • ② 오차는 «실제 − 예측», 제곱하면 부호가 사라짐. 1번 −1 → 1, 3번 2 → 4. 나누기 3까지 꼭.
  • 예상 오답: 오차를 제곱 안 하고 더함(−1 + 0 + 2 = 1) / 3으로 안 나눔(5).
  • «로지스틱 = 이름만 회귀, 하는 일은 분류»를 한 번 더.
