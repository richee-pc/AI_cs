🧪 5. 내 개선 실험 — 요소 ③

  • 받은 피드백과의 연결: ✎ 💡 피드백 «정확도 말고 위험한 사람을 몇 명 찾는지 보세요» → 내 «위험» 재현율이 0.012(670명 중 8명)라 위험한 사람을 거의 못 찾고 있었어요.
  • 가설: ✎ 모델을 Logistic Regression → Tree로 바꾸면 «위험» 재현율이 좋아질 것이다 — Logistic Regression은 선 하나로만 나눠서 거의 다 «정상»이라고 했는데, Tree는 «나이가 많고 허리둘레가 크면»처럼 조건을 겹쳐 나눠서 작은 위험 무리도 따로 찾을 수 있으니까.
  • 조작(바꾼 것 하나): ✎ 학습 위젯(모델)만 Logistic Regression → Tree. 입력 열 · 나누기 · 빈칸 처리는 그대로.
  • 결과(같은 지표, 전 → 후): ✎ «위험» 재현율 0.012 → 0.285 (670명 중 8명 → 191명) · 정확도 0.817 → 0.703
  • 해석(왜 · 우리 장면에 주는 뜻): ✎ 놓친 사람이 662명 → 479명으로 줄었어요. 대신 헛경보가 12명 → 613명으로 늘었어요. 보건소 안내는 «혈압 한 번 더 재기»라 헛경보의 손해는 작고, 놓치는 손해는 커요. 그래서 정확도가 떨어져도 Tree를 써요.
  • 편향 ☐ 확증 ☑ 선택 ☐ 역사적 ☐ 생존자 — 어떻게 겨냥했나: ✎ 검진 자료에 «정상»이 82 %로 많이 뽑혀 있어 Logistic Regression은 다수 쪽으로 기울었어요 → 조건으로 잘게 나누는 Tree로 바꿔서 적은 «위험» 무리도 따로 보게 했어요.

3 ~ 6절에서 이미 한 판단을 한 칸에 한두 줄로 모으는 곳이에요. 칸마다 «무엇을 했다 + 왜 + 우리 숫자 · 열 이름»이 다 들어가면 돼요. 5 · 6절을 먼저 쓰면 7절은 10분이면 끝나요. 구술 ②도 이 다섯 칸으로 준비해요.

글 칸

📝 7. 판단 근거 다섯 칸 — 요소 ④

  • 문제 정의 — ✎ 보건소가 혈압 재검을 누구에게 먼저 안내할지 정하는 문제라 «위험 / 정상» 분류로 했어요. 놓치면 병이 커지니 «위험» 재현율을 가장 중요하게 봐요.
  • 데이터 — ✎ 12,245명 · 입력 8열(성별 · 연령대코드 · 체중 · 허리둘레 · 공복혈당 · 트리글리세라이드 · 감마지티피 · 음주여부). 혈압 숫자 열은 «혈압판정»을 만든 열이라 뺐어요(넣으면 답을 보고 맞히는 셈). «위험»은 18 %로 적어요.
  • 모델 — ✎ Logistic Regression — 열마다 위험을 올리는 쪽인지 내리는 쪽인지 방향을 볼 수 있어서 보건소에 설명하기 좋아요.
  • 평가 — ✎ 정확도는 0.817로 높지만, 혼동 행렬을 보니 실제 위험 670명 중 8명만 찾고 662명을 놓쳤어요(재현율 0.012). 거의 다 «정상»이라고 찍은 셈이라 정확도만 보면 속아요.
  • 개선과 적용 — ✎ 모델을 Logistic Regression → Tree로 바꿔서 재현율 0.012 → 0.285(191명 찾음). 정확도는 0.703으로 떨어지고 헛경보가 613명이지만, 재검 안내는 비용이 작아서 Tree를 써요. 아직 10명 중 3명만 찾으니 다음엔 다른 모델 · 입력 열도 바꿔 보고, 검진 안 받는 사람이 많은 동네 자료로도 확인해 볼 거예요.
