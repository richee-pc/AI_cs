01 / 목적

이 과제로 무엇을 확인하는가

수업 시간에 안내한 목적 두 가지입니다. 채점의 축도 결국 이 두 가지입니다.

목적 1

선형에서 비선형으로의 확장

1학기 때 학습한 선형 자료구조(배열, 리스트 등)의 한계를 인식하고, 복잡한 다대다(Many-to-Many) 관계를 다루기 위해 비선형 자료구조(트리, 그래프)가 왜 필요한지 연결합니다.

목적 2

알고리즘으로의 브릿지(Bridge)

우리가 설계한 비선형 구조 안에서 데이터를 효율적으로 찾거나 순서를 정하기 위해 탐색(Searching) 및 정렬(Sorting) 알고리즘이 어떻게 작동해야 하는지 논리적으로 추론합니다.

채점자가 실제로 보는 것

조사를 얼마나 많이 했는지는 점수와 관계가 없습니다. 서비스 소개가 길어도 점수는 오르지 않습니다. 조사한 내용을 자료구조·알고리즘의 원리와 얼마나 정확하게 연결했는지만 봅니다.

2. 자료구조 비교 및 추상화 분석
[선형구조와의 차별성] 이 데이터를 기존의 선형 구조(배열, 리스트)로 처리했을 때 발생하는 한계점은 무엇인가요?

[비선형 구조 유형 선택 (체크)] 트리 (Tree) 구조 — 계층적 관계, 부모-자식, 디렉토리/조직도 형태
[비선형 구조 유형 선택 (체크)] 그래프 (Graph) 구조 — 네트워크 형태, 정점과 간선, 양방향/가중치 연결

[요소 정의] : 노드(정점, Vertex): 무엇을 의미하나요? / 간선(Edge): 무엇을 의미하나요? (가중치 여부 포함)

상위 수준으로 가려면

한계점을 “불편하다 / 느리다”로 쓰면 낮은 점수입니다. 탐색 비용, 관계 표현의 불가능성, 삽입·삭제 비용 중 두 가지 이상을 근거로 들어야 합니다. 노드·간선은 화면에 보이는 요소가 아니라 추상화된 관계로 정의하고, 가중치와 방향성이 필요한지 판단한 이유까지 쓰세요.

3. 탐색(Searching) 및 알고리즘 적용 시나리오
이 비선형 구조에서 특정한 목적지나 최적의 데이터를 찾아내기 위해 어떤 탐색 방식 (예: BFS, DFS, 최단 경로 알고리즘 등)이 필요하며, 그 이유는 무엇인가요?

상위 수준으로 가려면

알고리즘 이름만 적으면 낮은 점수입니다. “왜 다른 방식이 아니라 이것인가”에 답해야 합니다. 가중치가 있는지, 최단성이 필요한지, 모든 경로를 봐야 하는지 — 문제 조건과 연결해 다른 방식과 비교하면 최상위 수준입니다.

4. 데이터 정렬(Sorting) 및 최적화 아이디어 제안

04 / AI

AI 활용 3단계

이 과제는 생성형 AI로 아이디어와 자료를 얻은 뒤, 그것을 검토하고 고쳐서 제출하는 방식입니다. 아래 순서대로만 하면 규정을 지키면서 점수를 올릴 수 있습니다.

1

재료 모으기 — AI에게 아이디어와 자료를 받는다

다음 장의 프롬프트를 그대로 복사해 붙여 넣으면, AI가 주제 후보·비교표·개념 정리를 만들어 줍니다. 이건 내 답이 아니라 재료입니다.

2

검토하기 — 사실을 확인하고 내 주제에 맞는 것만 고른다

AI는 시간 복잡도나 알고리즘 설명을 틀리게 말할 때가 있습니다. 교과서와 수업 필기로 대조하고, 내 주제와 맞지 않는 내용은 버립니다. 프롬프트마다 AI가 [내가 직접 확인해야 할 것] 목록을 만들어 주도록 해 두었습니다.

3

다시 쓰기 — 내 언어로 옮기고, 마지막에 한 번 더 점검받는다

고른 재료를 보지 않고 내 말로 씁니다. 다 쓴 뒤 P5로 채점기준에 대조하고, P6로 그대로 베낀 문장이 남아 있지 않은지 확인합니다.

해도 되는 것

  • 자료 검색과 전문 자료의 요약
  • 주제 후보와 아이디어를 여러 개 받아 보기
  • 알고리즘 비교표·개념 설명 받기
  • 내가 쓴 글의 사실관계 확인받기
  • 내 논리에서 빠진 부분을 지적받기

하면 안 되는 것

  • AI가 써 준 문장을 그대로 옮겨 적기
  • 항목 전체를 통째로 대신 작성시키기
  • 사실 확인 없이 AI 설명을 그대로 믿기
  • 출처와 AI 활용 범위를 밝히지 않기
결과물 산출에 AI를 활용한 내용을 그대로 작성할 경우, 해당 평가 요소의 최하점이 부여됩니다. AI 답변 중 그대로 베끼고 싶어지는 문장이 나왔다면, 그게 바로 베끼면 안 되는 문장입니다. 읽고 창을 닫은 뒤 내 말로 다시 쓰세요. 그 과정이 이 과제가 평가하려는 능력 그 자체입니다.

보고서 끝에 반드시 적을 것

참고 자료의 출처와 AI를 어디에 어떻게 썼는지를 두세 줄로 적어 주세요. 예: “정렬 알고리즘의 시간 복잡도 비교표를 받아 참고함. 2차 정렬 기준이 필요하다는 점을 확인한 뒤 내 주제에 맞게 다시 판단하여 작성함.” 이 기록이 있으면 감점되지 않습니다. 없으면 감점됩니다.

[2] 핵심 개념 정리
    내가 알아야 할 용어와 원리를 3~5줄로 정리해 줘.
    시간 복잡도가 나오면 반드시 O 표기로 같이 적어 줘.

[3] 내가 직접 확인해야 할 것
    네 답변 중에서 사실 확인이 필요한 부분,
    그리고 내 주제에 맞는지 내가 판단해야 하는 부분을 목록으로 짚어 줘.

[4] 내 말로 바꿔 써야 할 문장
    내가 그대로 베끼면 안 되는 핵심 문장을 표시해 줘.

중요: 내 보고서에 그대로 넣을 수 있는 '완성된 문단'은 쓰지 마.
나는 네 답변을 재료로만 쓰고, 최종 문장은 내가 직접 쓸 거야.

이해했으면 "확인했어"라고만 답하고 기다려 줘.
1단계 · 재료 모으기

양식 1~4에 쓸 아이디어와 자료 받기

P1양식 1 — 탐구 주제 후보 뽑기 
[양식 1] 탐구 주제 명칭 및 선정 이유

내가 관심 있는 분야: (예 - 음식 배달 / 지하철 / SNS / 게임 매칭 /
  유튜브 추천 / 학교 시간표 … 아직 없으면 "아직 못 정했어"라고 쓰기)

[요청]
1. 이 분야에서 '자료를 저장하고, 찾고, 정렬하는 문제'가 뚜렷하게
   드러나는 탐구 주제 후보를 3개 제시해 줘.
2. 각 후보마다 아래를 알려 줘.
   - 컴퓨터가 실제로 처리해야 하는 문제를 한 줄로
   - 트리와 그래프 중 어느 쪽에 가까운지, 그 이유
   - 이 주제로 쓸 때 어려울 수 있는 점
3. 세 후보를 난이도 순으로 정렬하고, 고등학생이 수업 시간 안에
   정리하기에 가장 적당한 것을 추천해 줘. 추천 이유도 알려 줘.

내가 제출할 '선정 이유' 문장은 쓰지 마. 그건 내가 직접 쓸 거야.
P2양식 2 — 선형구조의 한계 + 노드·간선 재료 
[양식 2] 자료구조 비교 및 추상화 분석

내가 정한 주제: (여기에 주제 적기)

[요청]
1. 이 주제의 데이터를 배열이나 리스트(선형 구조)로 처리하면 어떤
   문제가 생기는지 아래 세 관점에서 설명해 줘.
   - 원하는 값을 찾는 데 드는 비용 (시간 복잡도로)
   - 여러 대상 사이의 '관계'를 표현할 수 있는지
   - 중간에 데이터를 넣거나 뺄 때의 비용
   각 관점마다 내 주제에 맞는 구체적인 상황을 하나씩 들어 줘.

2. 이 주제를 트리로 볼 때와 그래프로 볼 때를 표로 비교해 줘.
   표의 열: 무엇을 노드로 보는가 / 무엇을 간선으로 보는가 /
            이 관점의 장점 / 이 관점의 한계

3. 이 주제에서 간선에 '가중치'가 필요한 경우와 필요 없는 경우를
   각각 예로 들어 줘. 방향(단방향/양방향)이 중요해지는 경우도 알려 줘.

4. 마지막에 [내가 직접 판단해야 할 것] 목록을 붙여 줘.
P3양식 3 — 탐색 방식 비교표 받기 
[양식 3] 탐색 및 알고리즘 적용 시나리오

내 주제: (          )
내가 설계한 구조: 노드 = (      ) / 간선 = (      )
가중치: (있음 / 없음)   방향: (있음 / 없음)

[요청]
1. 이 구조에서 쓸 수 있는 탐색 방식(DFS, BFS, 다익스트라 등)을
   표로 비교해 줘.
   표의 열: 어떤 상황에 쓰는가 / 시간 복잡도 / 내 주제에 맞는 정도

2. 내 목적이 아래 셋 중 무엇이냐에 따라 답이 어떻게 달라지는지 알려 줘.
   - 가장 가까운 것 하나만 찾기
   - 가능한 모든 경로를 확인하기
   - 이동 비용(시간, 요금 등)이 가장 적은 경로 찾기

3. 가장 적합한 방식 하나를 추천하고, 그 방식이 '적합하지 않게 되는
   조건'도 함께 알려 줘.

4. 내가 이 선택의 근거를 직접 쓸 때 반드시 언급해야 할 키워드를
   3개만 알려 줘. 문장으로는 쓰지 마.
P4양식 4 — 정렬 기준·알고리즘 재료 (배점 30점) 
[양식 4] 데이터 정렬 및 최적화 아이디어

내 주제: (          )
탐색 결과로 얻는 것: (예 - 후보 가게 목록 / 경로 목록 / 추천 계정 목록)
예상 데이터 규모: (예 - 수십 개 / 수천 개 / 수십만 개)

[요청]
1. 이 결과를 사용자에게 보여 줄 때 쓸 만한 정렬 기준을 4가지
   제안하고, 각각 어떤 사용자에게 유리한지 알려 줘.

2. 1차 기준의 값이 같을 때 쓸 2차 기준을 예로 들어 줘.
   2차 기준이 없으면 어떤 문제가 생기는지도 알려 줘.

3. 정렬 알고리즘(선택/삽입/버블/병합/퀵/힙)을 표로 비교해 줘.
   표의 열: 평균 시간 복잡도 / 최악 시간 복잡도 / 안정 정렬 여부 /
            내 데이터 규모에 적합한 정도

4. 아래 두 상황에서 선택이 어떻게 달라지는지 알려 줘.
   - 결과가 10개뿐일 때
   - 결과가 10만 개인데 사용자에게는 상위 5개만 보여 주면 될 때
     (전체 정렬 말고 다른 방법이 있는지도 알려 줘)

5. '안정 정렬'이 내 주제에서 왜 중요할 수 있는지 예를 들어 줘.

6. 마지막에 [내가 직접 판단해야 할 것] 목록을 붙여 줘.
3단계 · 검토와 개선

내가 쓴 글을 고치기

P5채점기준표에 내 글을 직접 대조시키기 
아래는 내가 직접 쓴 보고서야. 채점기준에 맞춰 고칠 곳을 찾아 줘.

[채점기준]
① 탐구 주제 선정 및 문제 인식 (10점)
② 선형구조의 한계 분석과 비선형 구조 전환 논증 (20점)
③ 비선형 구조의 추상화 - 구조 선택, 노드와 간선 정의 (20점)
④ 탐색 알고리즘 적용 및 논거 제시 (20점)
⑤ 정렬 기준 설정 및 정렬 알고리즘의 원리 적용 (30점)

[내 보고서]
(여기에 내가 쓴 전문을 붙여넣기)

[요청]
1. 요소별로 지금 몇 점 수준인지 판정하고, 그렇게 본 근거가 된
   내 문장을 그대로 인용해 줘.
2. 사실이 틀린 곳을 찾아 줘. 특히 시간 복잡도나 알고리즘 설명이
   틀린 부분은 반드시 짚어 줘.
3. '불편하다 / 느리다 / 복잡하다'처럼 근거 없는 표현을 전부 찾아 줘.
4. 각 요소를 한 단계 올리려면 무엇을 더 생각해야 하는지 알려 줘.
   완성된 문장을 대신 써 주지는 말고, 방향과 질문으로만 알려 줘.
5. 내가 고쳐야 할 순서를 우선순위 3개로 정리해 줘.
P6제출 직전 — 그대로 베낀 문장 자가 진단 
아래 두 글을 비교해 줘.

[A. AI가 알려 준 내용]
(앞에서 AI가 준 답변 중 내가 참고한 부분을 붙여넣기)

[B. 내가 최종 제출할 글]
(내 최종본을 붙여넣기)

[요청]
1. B에서 A의 표현을 거의 그대로 옮긴 문장이 있으면 전부 찾아 줘.
2. 그 문장들이 '내 언어로 다시 쓴 것'인지 '베낀 것'인지 판정해 줘.
3. 베낀 것으로 보이는 문장은 내가 다시 쓸 수 있도록,
   그 문장이 말하는 핵심 내용만 한두 단어로 알려 줘.
   다시 써 주지는 마.
4. 마지막으로, 내 보고서에서 '내 생각'이 가장 잘 드러난 문장을
   3개 골라 줘. 그게 없으면 없다고 말해 줘.
