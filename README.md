# 인공지능 기초 · 2학기 안내

2026학년도 2학기 2학년 진로 선택 「인공지능 기초」 **학생 안내 페이지**입니다.

한 학기 운영을 학생에게 안내하고, 학기 중 언제든 다시 열어 볼 수 있도록 만들었습니다.
오리엔테이션 때 프로젝터로 띄워 쓰는 것도 겸합니다.

| 항목 | 내용 |
|---|---|
| 교육과정 | 2022 개정 교육과정 · 진로 선택 |
| 이수 학점 | 3학점 (주 3시간) · 2학기 단독 완성 |
| 총 차시 | 인기A 50 · 인기D 49 · 인기E 50차시 |
| 평가 반영 | 정기고사 50% (1차 25 + 2차 25) · 수행평가 50% (윤리 토론 20 + AI 프로젝트 30) |
| 서술·논술형 | 0% (학기 초 확정 평가 계획) |
| 성적 산출 | 성취도 5단계(A~E) + 석차 5등급 모두 산출 |

## 날짜 공개 스위치

수행평가와 정기고사의 **정확한 날짜는 지금 가려져 있습니다.** 확정되면
`index.html` 맨 아래 `<script>` 안의 한 줄만 고치면 전부 공개됩니다.

```js
var LOCKED = true;   // false 로 바꾸면 아래가 모두 열립니다
```

`LOCKED` 하나가 다음 네 곳을 함께 여닫습니다.

| 위치 | 가려지는 것 |
|---|---|
| `#class` | 분반별(A/D/E) 정확한 실시일 표 |
| `#exam` | 정기고사 날짜와 출제 범위 |
| `#pa1` | 수행평가 ① 채점 기준표 · 진행 방식 · 논제 목록 |
| `#pa2` | 수행평가 ② 채점 기준표 · 단계별 진행 |

가려진 상태에서도 실제 날짜는 `data-when` 속성과 분반별 표에 그대로 들어 있습니다.
**페이지 소스를 열면 보인다는 뜻**이므로, 외부에 절대 알려지면 안 되는 날짜라면
스위치가 아니라 해당 내용을 파일에서 지워야 합니다.

## 학교 구글 아이디

아이디는 **1학년 때 학번**으로 만들어져 있습니다.

```
ch25 + 1 + 반(2자리) + 번호(2자리) + @gsuite.gen.go.kr
예)  1학년 3반 7번  ->  ch2510307@gsuite.gen.go.kr
```

페이지의 「내 구글 아이디 찾기」는 이 규칙을 계산해 보여 줄 뿐이며,
**학생 명단은 이 저장소 어디에도 들어 있지 않습니다.**
비밀번호도 페이지에 적지 않습니다 — 수업 시간에 따로 안내합니다.

## 파일 구조

```
.
├── index.html        # 안내 페이지 — 내용 수정은 이 파일만 고치면 됨
├── app.py            # Streamlit 진입점 (index.html을 읽어 렌더링)
├── requirements.txt
└── README.md
```

`index.html` 은 그 자체로 완성된 문서입니다. **파일을 브라우저로 바로 열어도** 배포한 것과 똑같이 보입니다.

## 배포하기

### GitHub Pages — 권장

`index.html` 이 저장소 최상위에 있으므로 Pages를 켜면 바로 서비스됩니다.

1. 저장소 **Settings → Pages** 로 들어갑니다.
2. Source 를 **Deploy from a branch**, Branch 를 **`main` / `(root)`** 로 지정하고 **Save**.
3. 1~2분 뒤 `https://richee-pc.github.io/AI_cs/` 주소가 열립니다.

iframe 없이 브라우저가 문서를 직접 렌더링해서 모바일에서도 가장 깔끔하게 보입니다.

### Streamlit Community Cloud

1. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인합니다.
2. **New app** → 저장소 선택 → Branch `main` → Main file path `app.py` → **Deploy**.
3. 몇 분 뒤 `https://<앱이름>.streamlit.app` 주소가 생성됩니다.

이후 `index.html` 을 수정해 push하면 배포된 페이지에 자동 반영됩니다.

## 로컬에서 실행하기

`index.html` 을 더블클릭해 열면 끝입니다. Streamlit으로 확인하려면:

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 열립니다.

## 안내문을 수정할 때

`index.html` 하나만 고치면 됩니다. `app.py` 는 건드릴 필요가 없습니다.

- 날짜가 바뀌었다면 → `#months`(월별 카드)와 `#class`(분반별 표) **두 곳 모두** 수정
- 배점이 바뀌었다면 → `#grade` 막대(`.bar`)와 `#pa1`·`#pa2` 채점표(`.crit`) **모두** 수정
- 퀴즈 문항은 맨 아래 `<script>` 의 `QS` 배열에서 고칩니다
- FAQ는 없앴고, 그 자리에 계정·사이트 링크(`#tools`)가 들어갑니다
- 색과 글꼴은 파일 위쪽 `:root` 의 CSS 변수에서 한 번에 바꿉니다
  (라이트·다크 두 벌이 있으니 **양쪽 모두** 수정)
