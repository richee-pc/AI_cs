꼭 알아 둘 낱말 — 파라미터와 친구들 63쪽 옆 «파라미터» · 93쪽

성적 = a × 공부 시간 + b

파라미터모델을 이루는 변수이면서 학습 결과로 모델이 갖는 값. 위 직선의 a · b, 신경망의 가중치. 학습으로 잘 조정할수록 성능이 높아진다(63쪽).
하이퍼파라미터학습으로 정해지지 않고 사람이 직접 정하는 설정값. k-최근접 이웃의 k, 학습률, 트리 깊이(93쪽).
속성 · 특성 · 독립변수답을 짐작하는 데 쓰는 힌트 열. 위에서는 «공부 시간».
레이블 · 정답 · 종속변수맞히려는 값. 위에서는 «성적». 레이블이 붙은 데이터가 있어야 지도학습이 된다.
데이터셋학습에 쓰는 데이터 묶음. 훈련 데이터 · (검증 데이터) · 테스트 데이터로 나눈다(101쪽).
모델학습이 끝나 «a · b 가 정해진» 결과물. 새 공부 시간을 넣으면 성적을 내놓는다.

k-평균은 어떻게 무리를 정하나
  1. k 정하기 — 몇 무리로 나눌지 사람이 정합니다(여기서는 2).

  5. 반복 — ③ · ④를 되풀이해 더는 아무 점도 무리를 바꾸지 않으면 끝.

점들이 실제로 두 덩어리로 모여 있어서, 중심이 몇 번 옮겨 다니다 각 덩어리의 한가운데에 자리 잡습니다. 다만 처음 중심을 어디 찍느냐에 따라 결과가 달라질 수 있고, 무리의 이름(«운동형», «공부형» 등)은 컴퓨터가 아니라 사람이 평균값을 보고 붙입니다.

문제 상황 「그 여름, 우리 학교에서 생긴 일」 · 데이터 탐구 ① 시간에 함께 읽습니다

올해 여름은 유난히 길었다. 7월 초에 시작된 폭염 특보는 9월이 되어서도 풀리지 않았고, 교실 에어컨은 1교시부터 쉬지 않고 돌아갔다. 행정실에서는 “이번 달 전기 요금이 작년보다 훨씬 많이 나왔다”는 이야기가 들려왔다.

보건실은 늘 붐볐다. 보건 선생님은 “머리가 아프다, 어지럽다고 오는 학생이 작년보다 확실히 많다”고 하셨다. 2학년 민준이는 “밤에 더워서 잠을 못 자니까 낮에 집중이 안 되고, 시험 생각을 하면 더 답답해요”라고 말했다. 옆에 계시던 담임 선생님은 “요즘 애들은 원래 휴대폰 때문에 늦게 자잖아” 하며 고개를 저으셨다. 폭염 때문에 체육 수업은 실내로 바뀌었고, 체육대회는 두 번이나 미뤄졌다. 쉬는 시간에 운동장에서 공을 차는 학생도 눈에 띄게 줄었다.

급식실에서는 “더워서 입맛이 없다”는 말과 함께 잔반통이 금방 찼다. 대신 매점과 학교 앞 편의점의 차가운 음료는 날개 돋친 듯 팔렸고, 분리수거함에는 플라스틱 컵이 넘쳐났다.

그러던 어느 날, 학교 뒷산 약수터에 ‘음용 부적합’ 안내문이 붙었다. 주말마다 물을 떠 가시던 동네 할머니는 “비가 한꺼번에 쏟아진 뒤로 물맛이 이상하더라” 하셨고, 뉴스에서는 상수원에 녹조가 번졌다는 소식이 이어졌다.

학생회는 다음 학기 예산으로 무엇부터 해야 할지 고민에 빠졌다. 운동장에 그늘막을 늘릴까, 보건실 물품을 채울까, 정수기를 바꿀까, 아니면 전기를 아끼는 캠페인을 할까? 학생회장이 말했다. “느낌 말고, 데이터로 확인하고 정하자.”

이 여름, 우리 학교에서 생긴 일 가운데 여러분은 무엇이 «진짜 문제»라고 생각하나요? 그것은 어떤 데이터로 확인할 수 있을까요?

정답은 없습니다. 같은 이야기를 읽어도 누구는 더위와 건강을, 누구는 물을, 누구는 전기와 쓰레기를 문제로 봅니다. 이야기 속 말 중에는 «느낌»이나 «소문»도 섞여 있으니, 무엇이 데이터로 확인할 수 있는 것인지부터 가려 보세요. 같은 실마리를 고른 모둠이 여럿이어도 괜찮습니다 — 찾는 데이터와 해석이 달라 발표 때 좋은 토의거리가 됩니다.

평균제곱오차(MSE)란? — «평균적으로 얼마나 틀렸나»를 재는 점수
  1. 오차 = 실제 값 − 예측 값. 그림의 빨간 선 길이입니다.
  2. 제곱합니다. 위로 틀린 것(+)과 아래로 틀린 것(−)이 서로 지워지지 않게 하고, 크게 틀린 것을 더 크게 벌줍니다.
  3. 모든 점의 제곱을 더해 점 개수로 나눕니다(평균).

예) 실제 성적 70 · 80 · 90을 72 · 77 · 90으로 예측했다면 오차는 −2 · 3 · 0 → 제곱 4 · 9 · 0 → 평균 (4 + 9 + 0) ÷ 3 ≈ 4.3. MSE가 0에 가까울수록 잘 맞는 직선이고, 컴퓨터는 MSE가 가장 작아지는 기울기와 절편을 찾습니다(최소제곱법 · 경사하강법). 단위가 «점²»이라 크기 자체보다 다른 직선 · 다른 모델과 견줄 때 씁니다.

경사하강법이 하는 일이 이것입니다. «지금 직선이 얼마나 틀렸는지(MSE)»를 재고, 덜 틀리는 쪽으로 조금씩 옮기기를 되풀이합니다. 한 번에 얼마나 옮길지를 정하는 값이 학습률입니다 — 너무 작으면 하루 종일 걸리고, 너무 크면 골짜기를 훌쩍 뛰어넘어 영영 못 찾습니다. 그래서 0과 1 사이의 적당한 값을 씁니다.

«50걸음»을 눌러도 절편이 느릿느릿 움직이지요? 공부 시간은 1~10인데 성적은 40~90이라 두 축의 크기가 너무 다르기 때문입니다. 그래서 실제 학습에서는 값의 범위를 0~1로 맞춰 주는 정규화를 먼저 합니다 — 아래 코랩 코드의 MinMaxScaler가 그 일을 합니다. 느리게 움직이는 이 화면이 정규화가 왜 필요한지 보여 주는 셈입니다.

② 직선과 오차 — 선형 회귀 95쪽

직선 y = a·x + b. a 는 «x 가 1 늘 때 y 가 얼마나 느나»(기울기), b 는 x=0 일 때 값(절편).

점 (1, 3), (2, 5), (3, 6) · 직선 y = 1.5x + 1.7

MSE(평균제곱오차) = 오차(Error)를 제곱(Squared)해 평균(Mean) — 제곱하는 까닭은 +/− 가 서로 지워지지 않게, 큰 실수에 벌을 더 주려고.

③ 경사하강법 — 눈 감고 산 내려가기 95쪽 그림 Ⅱ-14

④ 시그모이드 — 로지스틱 회귀의 농구 슛 94쪽

쉬는 시간에 매점에 갈지 정합니다. 따지는 것은 세 가지인데, 사람마다 중요하게 보는 정도가 다릅니다. 그 «중요한 정도»가 바로 가중치입니다. 조건을 켜고 끄면서, 가중치도 바꿔 보세요.

교과서 117쪽 그림과 같은 계산입니다. 입력 1·0·1에 가중치 0.3·0.8·0.4를 곱해 더하면 0.7. 교과서는 편향이 -0.1이라 0.6이 됩니다 (여기서는 편향을 -0.5에서 시작하니 0.2 — 편향 손잡이를 -0.1로 옮기면 교과서 값과 같아집니다). 이 값을 활성화 함수에 넣고, 나온 값이 임계값을 넘으면 «참», 못 넘으면 «거짓»을 내보냅니다. 여기서는 교과서와 같이 렐루를 쓰고 임계값을 0으로 두었습니다.

퍼셉트론 하나로 풀리는 문제, 안 풀리는 문제 Ⅱ-06 · 118쪽

이번에는 입력이 둘입니다. 가중치와 편향을 움직여 네 줄이 모두 초록이 되게 만들어 보세요. AND와 OR은 금방 됩니다. 그런데 XOR은…

XOR은 아무리 맞춰도 안 됩니다 — 고장이 아닙니다. 퍼셉트론 하나는 결국 직선 하나를 긋는 일입니다. 그런데 XOR은 «(0,1)과 (1,0)은 참, (0,0)과 (1,1)은 거짓» — 직선 하나로는 이 넷을 갈라놓을 수 없습니다. 실제로 1960년대에 이것 때문에 인공신경망 연구가 한 번 얼어붙었습니다. 해결책은 퍼셉트론을 여러 개 이어 붙이는 것이었습니다.

층을 하나 넣었더니 풀렸습니다 Ⅱ-06 · 118~119쪽

입력과 출력 사이에 은닉층을 한 층 넣었습니다. 첫 층이 «둘 중 하나라도(OR)»와 «둘 다는 아님(NAND)»을 각각 맡고, 출력층이 그 둘을 «둘 다(AND)»로 합칩니다. 직선 두 개로 갈랐다고 보면 됩니다.

여기서 «딥»이 나옵니다. 은닉층이 여러 개가 되면 심층 신경망, 그것으로 하는 기계학습이 딥러닝입니다. 2016년 이세돌 9단과 둔 알파고는 은닉층이 13개였습니다.

층이 깊어지면 무엇이 좋아질까요? 사람이 «색을 봐라», «모양을 봐라»라고 알려 주지 않아도 무엇을 봐야 할지 스스로 찾아냅니다(특징 추출). 그래서 이미지·음성·글처럼 «무엇이 특징인지 말하기 어려운» 데이터에서 특히 강합니다. 대신 학습에 시간이 훨씬 오래 걸립니다.

실습에서 이 코드를 처음부터 다 짜지는 않습니다. 노트북에 거의 적혀 있고, 여러분이 할 일은 «이 줄이 무엇을 하는 줄인지 아는 것»과 빈칸을 채우는 것입니다. 여기서 한 번 읽고, 바로 아래에서 코랩으로 직접 돌려 보세요.

세 코드가 전부 같은 모양입니다. ① 라이브러리 가져오기 → ② 데이터 읽기 → ③ 속성(x)과 정답(y) 나누기 → ④ 훈련용·테스트용 나누기 → ⑤ 모델 만들고 fit() → ⑥ predict()로 맞혀 보고 점수 내기. 가운데 «모델» 자리만 바뀝니다.

① 예측 모델 — 도서관·공연장 수로 청년 인구 맞히기교과서 104~107쪽
# ① 필요한 것 가져오기
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# ② 데이터 읽기
df = pd.read_csv('youth population.csv')

# ③ 속성 x 와 정답 y 나누기  ← 대괄호 두 겹인 이유: 열을 «여러 개» 고르기 때문
x = df[['도서관', '공연장']]
y = df[['청년']]

# ④ 훈련용 80% · 테스트용 20% 로 나누기  ← 한 줄에 네 개를 한꺼번에 받습니다
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=0)

# ⑤ 모델 만들고 학습시키기
model = LinearRegression()
model.fit(x_train, y_train)

# ⑥ 맞혀 보고 점수 내기
Predicted = model.predict(x_test)
mean_squared_error(y_test, Predicted)   # 평균제곱오차 — 작을수록 좋음
model.score(x_test, y_test)             # 결정계수 — 1에 가까울수록 좋음

여기서 처음 보는 문법 셋. ① df[['A','B']] — 대괄호가 두 겹이면 «열 여러 개»입니다(한 겹은 한 열). ② test_size=0.2 — 이렇게 «이름=값»으로 넘기는 것을 키워드 인자라고 합니다. ③ a, b, c, d = ... — 오른쪽이 내놓는 값 네 개를 왼쪽 네 변수가 순서대로 받습니다(언패킹).

② 분류 모델 — 붓꽃 종 가려내기 (k-최근접 이웃)교과서 108~112쪽
from sklearn.neighbors import KNeighborsClassifier
import sklearn.metrics

df = pd.read_csv('iris.csv')
x = df[['꽃잎 길이', '꽃잎 너비', '꽃받침 길이', '꽃받침 너비']]   # 열 이름의 띄어쓰기까지 똑같이
y = df['종']
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=10)

model = KNeighborsClassifier()      # ← 위 코드에서 이 한 줄만 바뀌었습니다
model.fit(x_train, y_train)
Predicted = model.predict(x_test)

sklearn.metrics.confusion_matrix(y_test, Predicted)   # 오분류표
sklearn.metrics.accuracy_score(y_test, Predicted)     # 정확도 0.9666…

분류는 «맞았다/틀렸다»를 표로 봅니다. 30개를 맞혀 본 결과가 대각선에 10·12·7 — 29개를 맞히고 1개를 틀렸습니다. 정확도 = 맞힌 수 ÷ 전체 = 29/30 ≒ 0.967. 시험에 오분류표를 주고 정확도를 계산하게 하는 문제가 나옵니다.

정확도만 보면 속을 때가 있습니다. 스팸함으로 보내면 못 보게 되니 «스팸이라 했는데 진짜 스팸인 비율»(정밀도)이 중요하고, 악성 종양은 하나라도 놓치면 안 되니 «진짜 환자를 얼마나 찾아냈나»(재현율)가 중요합니다. 무엇을 틀리면 더 큰일인지에 따라 지표를 고릅니다.

③ 딥러닝 모델 — 독버섯 가려내기 (케라스)교과서 126~130쪽
from tensorflow import keras

# 글자로 된 값을 숫자로 바꾸기 (모델은 숫자만 먹습니다)
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
for i in list(df.columns.values):
    df[i] = le.fit_transform(df[i])

model = keras.Sequential()                                     # 빈 모델
model.add(keras.layers.Dense(64, activation='relu'))     # 은닉층 ①
model.add(keras.layers.Dense(8,  activation='relu'))     # 은닉층 ②
model.add(keras.layers.Dense(1,  activation='sigmoid'))  # 출력층 — 둘 중 하나라서 1개

model.compile(optimizer='adam', loss='binary_crossentropy', metrics='accuracy')
history = model.fit(x_train, y_train, epochs=15, batch_size=256)
model.evaluate(x_test, y_test)     # [손실함수값, 정확도]

층 세 줄이 신경망 전부입니다. 앞서 눌러 본 퍼셉트론이 Dense 한 줄 안에 64개, 8개 들어 있다고 보면 됩니다. epochs=15는 «전체 데이터를 15번 되풀이해 보라», batch_size=256은 «256개마다 한 번씩 가중치를 고치라»는 뜻입니다.

정규화 한 줄로 정확도가 0.975 → 0.991이 됩니다. 값의 범위가 제각각이면 큰 숫자를 가진 속성 쪽으로 모델이 쏠립니다. MinMaxScaler로 전부 0~1 사이로 맞춰 주면 학습이 훨씬 잘됩니다(교과서 130쪽). 여기서도 결국 «데이터를 잘 치웠는가»가 성능을 갈랐습니다.

읽었으면 이제 직접 돌려 볼 차례입니다. 위 세 코드를 빈칸만 채워 실행하는 코랩 노트북으로 만들어 두었습니다. 데이터도 안에 들어 있어 올릴 것이 없습니다 — 바로 아래 «코랩에서 직접»을 보세요.

학습 유형과 알고리즘 — Ⅱ-03 · Ⅱ-04

지도학습 문제와 정답을 함께 주고 공부시키기 입력 데이터와 그에 대응하는 정답(레이블)을 함께 주어 관계를 학습하는 방법. 하는 일 — 분류(어느 집단인가)와 예측(숫자가 얼마일까).
비지도학습 정답 없이 닮은 것끼리 묶게 하기 레이블 없는 데이터에서 숨은 구조나 패턴을 찾는 방법. 하는 일 — 군집화. 추천 시스템·이상 탐지가 여기 속한다.
강화 학습 상과 벌을 주며 스스로 익히게 하기 환경과 주고받으며 보상을 최대로 만드는 행동을 배우는 방법. 탐험(새로 해 보기)과 이용(아는 대로 하기) 사이의 균형이 핵심. 챗GPT의 RLHF도 여기.
레이블 데이터에 붙은 정답 딱지 정답 데이터를 부르는 다른 이름. 강아지 사진에 붙은 «강아지» 표시. 레이블이 충분히 없으면 지도학습을 쓸 수 없다.
k-최근접 이웃 (K-NN) 가장 가까운 k개를 보고 다수결 새 데이터 주위의 이웃 k개를 살펴 분류하는 지도학습 알고리즘. k를 어떻게 잡느냐에 따라 답이 달라진다.
k-평균 중심을 옮겨 가며 k덩어리로 묶기 데이터를 k개 군집으로 나누는 비지도학습 알고리즘. 중심 배정 → 평균으로 중심 이동을 되풀이한다. 이름이 비슷한 K-NN과 헷갈리지 말 것. 이쪽은 군집화다.
하이퍼파라미터 사람이 직접 넣어 줘야 하는 값 학습으로 정해지지 않고, 사용자가 설정하는 값. k, 학습률, 에포크, 은닉층 수. 학습으로 «정해지는» 값은 파라미터(가중치·편향)다. 이 둘의 구분이 시험에 나온다.
선형 회귀분석 점들 사이를 지나는 가장 좋은 직선 찾기 속성과 레이블 사이의 직선 관계를 찾아 새 값을 예측하는 지도학습 방법. 가장 좋은 직선 = 평균제곱오차가 가장 작은 직선(최소제곱법).
경사하강법 덜 틀리는 쪽으로 조금씩 옮겨 가기 오차가 가장 작은 지점을 찾기 위해, 기울기의 반대 방향으로 조금씩 이동하기를 되풀이하는 방법. 한 걸음의 크기가 학습률. 너무 크면 골짜기를 넘어가 학습에 실패한다.

모델 만들기와 평가 — Ⅱ-05

훈련 데이터 · 테스트 데이터 공부할 학습지와, 실력을 재는 시험지 모델 학습에 쓰는 데이터와, 학습에 쓰지 않고 남겨 두었다가 성능 평가에 쓰는 데이터. 공부한 문제만 잘 푸는 건 실력이 아니므로 반드시 나눈다.
평균제곱오차 (MSE) 틀린 만큼을 제곱해서 평균 낸 값 실제값과 예측값 차이를 제곱해 평균한 것. 작을수록 좋다. 예측 모델을 잴 때 쓴다. 제곱하는 이유는 «덜 맞힌 것»과 «더 맞힌 것»이 상쇄되지 않게 하려고.
결정계수 (R²) 평균만 찍는 것보다 얼마나 나은가 1에 가까울수록 실제값에 가깝게 예측하고, 0에 가까우면 평균을 맞히는 정도. 예측 모델을 잴 때 쓴다.
오분류표 맞힌 것과 틀린 것을 네 칸으로 정리한 표 실제값과 예측값을 맞대어 TP·FP·FN·TN 개수를 적은 표. 여기서 정확도·정밀도·재현율이 모두 나온다.
정확도 · 정밀도 · 재현율 전체 중 맞힌 비율 / 참이라 한 것 중 진짜 / 진짜 중 찾아낸 것 정확도 = (TP+TN)÷전체 · 정밀도 = TP÷(TP+FP) · 재현율 = TP÷(TP+FN). 스팸 분류는 정밀도, 악성 종양 진단은 재현율이 중요하다.
과적합 연습 문제만 외워 버린 상태 학습 데이터에 지나치게 맞춰져 새 데이터에서는 잘 못 맞히는 것. 훈련 성능과 테스트 성능을 견주어 보면 알 수 있다 — 차이가 크면 과적합.

인공신경망과 딥러닝 — Ⅱ-06 · Ⅱ-07

퍼셉트론 곱하고 더해서 기준을 넘는지 보는 작은 계산기 입력값을 받아 처리해 출력값을 내는 인공신경망의 최소 단위. 뉴런의 신호 전달을 흉내 냈다. «최소 단위는 뉴런이다»는 틀린 말이다.
가중치 · 편향 각 입력을 얼마나 중요하게 볼지 / 기본으로 깔고 가는 값 입력마다 곱해지는 값이 가중치, 그 합에 더하는 상수가 편향. 학습으로 «정해지는» 값이다(파라미터). 사람이 정하는 하이퍼파라미터와 다르다.
활성화 함수 더한 값을 내보내기 좋은 모양으로 바꿔 주는 것 렐루(0보다 작으면 0, 크면 그대로) · 시그모이드(0~1 사이 확률로). 이게 없으면 층을 아무리 쌓아도 직선 하나와 같아진다.
은닉층 · 심층 신경망 입력과 출력 사이에 낀 층 / 그게 여러 개인 것 입력층과 출력층 사이에서 연산을 수행하는 층이 은닉층. 은닉층이 여러 개면 심층 신경망이고, 이것을 쓰는 기계학습이 딥러닝이다. 알파고는 은닉층이 13개였다.

1. 전통적 프로그래밍과 기계학습의 가장 큰 차이는 무엇인가요?

«규칙을 누가 만드는가»입니다. 전통적 프로그래밍은 사람이 규칙을 단계별로 설계해 코드로 적습니다. 기계학습은 사람이 데이터와 결과만 주고, 컴퓨터가 규칙을 찾아냅니다. 그래서 절차가 명확한 문제(정렬)는 전통적 방법이, 절차를 적기 어려운 문제(이미지 인식)는 기계학습이 낫습니다.

2. 기계학습으로 문제를 푸는 다섯 단계를 순서대로 말해 보세요.

문제 정의 → 데이터 선정·수집·전처리 → 기계학습 유형과 알고리즘 선정 → 모델 생성 → 성능 평가 및 수정. 성능이 모자라면 앞 단계로 되돌아갑니다 — 한 번에 끝나는 일이 아닙니다. (교과서 63쪽 그림 Ⅱ-3)

3. 좋은 데이터의 선정 기준 네 가지는?

정확성 · 관련성 · 시의성 · 다양성입니다. 오류가 없어야 하고(정확성), 풀려는 문제와 관련이 있어야 하고(관련성), 시기적으로 적절해야 하고(시의성), 여러 상황을 담고 있어야 합니다(다양성). «무조건 최신 데이터가 좋다»는 틀린 말입니다 — 극단적으로 최신인 것만 학습해도 성능이 떨어집니다.

4. 데이터 전처리 네 가지를 예와 함께 말해 보세요.

변환(«남자»→«남»처럼 표현 통일) · 통합(파일 두 개를 하나로) · 정제(이상치·결측치 고치거나 지우기) · 축소(연락처처럼 필요 없는 열 빼기). 위 전처리 체험에서 누른 단추들이 순서대로 이 넷이었습니다.

5. 다음은 어떤 학습 유형일까요? — ① 신용카드 이상 거래 탐지 ② 바둑 최적 전략 ③ 스팸 메일 걸러내기

① 비지도학습 — 무엇이 이상인지 정답을 주지 않고, 평소 패턴에서 벗어난 것을 찾습니다.
② 강화 학습 — 게임의 상태·행동·보상을 데이터로 씁니다.
③ 지도학습 — 스팸/정상이 이미 구분된 메일로 학습합니다.
판단 기준은 늘 하나입니다 — 정답이 함께 주어지는가, 보상으로 배우는가.

6. k-최근접 이웃 알고리즘에 대한 설명 중 틀린 것은? — ① 가까운 이웃을 살펴 분류한다 ② k는 하이퍼파라미터다 ③ 비지도학습이다 ④ k 값에 따라 결과가 달라진다

③이 틀렸습니다. k-최근접 이웃은 레이블이 있는 데이터를 쓰므로 지도학습입니다. 비지도학습인 것은 이름이 비슷한 k-평균(군집화)입니다. 또 «k는 학습으로 자동 계산된다»도 틀린 말입니다 — 사람이 정합니다.

7. 데이터를 훈련용과 테스트용으로 나누는 이유는?

처음 보는 데이터에도 잘 맞히는지 확인하기 위해서입니다. 학습에 쓴 데이터로 점수를 매기면 «공부한 문제만 푼 시험»이라 실력을 알 수 없습니다. 훈련 성능은 좋은데 테스트 성능이 크게 떨어지면 과적합을 의심합니다.

8. 아래 오분류표에서 정확도를 구해 보세요. (클래식 음악 분류 · 전체 240개)

«클래식 아님»을 맞힌 것 90, «클래식»을 맞힌 것 100, 나머지 20과 30은 틀린 것입니다.
정확도 = (90 + 100) ÷ 240 = 190/240 ≒ 0.792, 약 79.2%입니다. 정확도는 대각선(맞힌 것)의 합 ÷ 전체입니다. (교과서 111쪽 예제 2)

9. 퍼셉트론 하나로는 XOR을 풀 수 없습니다. 왜 그럴까요?

퍼셉트론 하나는 결국 직선 하나를 긋는 일이기 때문입니다. XOR은 (0,1)·(1,0)이 참이고 (0,0)·(1,1)이 거짓이라, 참인 둘과 거짓인 둘이 대각선으로 엇갈려 있습니다. 직선 하나로는 못 가릅니다. 은닉층을 넣어 층을 쌓으면 풀립니다 — 이것이 다층 퍼셉트론이 나온 이유이고, 딥러닝의 출발점입니다.

10. 딥러닝이 딥러닝 아닌 기계학습보다 나은 점과, 그렇지 못한 점은?

나은 점 — 데이터가 많을수록 성능이 더 좋아지고, 사람이 특징을 지정해 주지 않아도 스스로 찾아냅니다(특징 추출). 그래서 이미지·음성·글에서 특히 강합니다.
그렇지 못한 점 — 학습 시간이 훨씬 오래 걸립니다. 사람이 정해야 할 하이퍼파라미터도 훨씬 많습니다.
