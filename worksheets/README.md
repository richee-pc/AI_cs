## 복사실 · 프린터 설정

1. 용지 **B4** (257 × 364 mm, 한국 복사용 B4)
2. **양면** 인쇄
3. 넘김 **긴 변** (세로 용지에서 뒤집어도 위·아래가 맞습니다)
4. 배율 **100% · 실제 크기** (여백은 PDF에 이미 들어 있습니다)

B4 용지가 없으면 A4로 **용지에 맞춤** · 양면으로도 한 장입니다. 글씨만 조금 작아집니다.

수업 페이지의 **수업 활동 → ⑫ 탐색 학습지 함께 풀기** 에서도 같은 파일을 받을 수 있습니다.
