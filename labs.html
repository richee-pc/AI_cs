1데이터 보기 — 붓꽃(iris)15분 · 데이터 시각화
File
iris→Data Table→Feature Statistics·Distributions·Scatter Plot
  1. File 을 캔버스에 놓고 두 번 눌러 iris 를 고릅니다. 아래 표에서 iris(품종)의 Role 이 target 인지 봅니다.
  2. Data Table 을 이어 행 수(150)·열 수·빈칸(?)을 확인합니다.
  3. Feature Statistics — 열마다 평균·최소·최대·분산. Distributions — 한 열의 분포를 품종별 색으로.
  4. Scatter Plot — x·y 축을 바꿔 보다가 Find Informative Projections(돋보기)를 누르면 품종이 가장 잘 갈리는 두 축을 찾아 줍니다.

확인세 품종을 가장 잘 가르는 두 속성은? 그 그림에서 겹치는 두 품종은?

2분류 — 타이타닉 생존(titanic)20분 · Tree · kNN
File
titanic→Tree→Tree Viewer·kNN→Test and Score→Confusion Matrix
  1. File 에서 titanic — status(객실) · age(어른/아이) · sex 세 열, 정답 survived.
  2. Tree 를 File 에 잇고 Tree Viewer 로 나무 그림을 봅니다. 맨 위 질문은?
  3. Tree 설정 Limit the maximal tree depth 를 2 → 3 → 10 으로 바꾸며 그림이 어떻게 변하는지 봅니다(깊으면 외우기 = 과적합).
  4. kNN 을 놓고 Number of neighbors(k) · Metric(거리) · Weight(가까울수록 큰 표)를 살펴봅니다.
  5. Test and Score — File 을 Data 에, Tree 와 kNN 을 Learner 에 잇습니다. 기본 교차 검증(10-fold)은 데이터를 10조각으로 나눠 10번 시험 본 평균입니다.
  6. Confusion Matrix 를 Test and Score 뒤에 — 누구를 놓쳤나(재현율), 헛경보는(정밀도)?

확인CA(정확도) 기준 더 나은 모델은? 기준선(전부 «사망»이라 찍기)보다 얼마나 나은가?

3회귀 — 집값 예측(housing)20분 · Linear Regression
File
housing→Linear Regression→Data Table
계수·Test and Score·Predictions
  1. File 에서 housing(보스턴 집값) — 정답 MEDV(집값 중앙값, 천 달러), 특성 13개(방 수 RM, 저소득층 비율 LSTAT …).
  2. Linear Regression 의 출력 중 Coefficients 를 Data Table 로 — 계수 + 는 집값을 올리는 쪽, − 는 내리는 쪽.
  3. Test and Score — 예측이라 지표가 MSE · RMSE · MAE · R2 로 바뀝니다. RMSE 는 «평균 몇 천 달러 빗나가나».
  4. Predictions 에 모델과 File 을 이어 행마다 실제값과 예측값을 비교합니다.
  5. (비교) Random Forest 를 하나 더 Test and Score 에 꽂아 R2 를 견줘 봅니다.

확인집값을 가장 크게 올리는 특성 · 내리는 특성은? 계수 크기는 단위에 따라 달라진다는 점도 기억!

4군집 — 동물 유형 묶기(zoo)20분 · k-Means
File
zoo · type=skip→k-Means
2~8 실루엣→Box Plot·Scatter Plot·Data Table
정답과 비교
  1. File 에서 zoo(동물 101종 · 털 · 깃털 · 알 · 우유 · 다리 수 …). 정답 열 type 의 Role 을 skip 으로 — 정답을 숨겨야 비지도학습입니다.
  2. k-Means 에서 From 2 to 8 을 고르면 k마다 실루엣 점수를 계산해 가장 좋은 k를 표시합니다.
  3. Box Plot 에서 Subgroups: Cluster 로 놓고 milk · feathers · fins 같은 열을 보며 무리마다 특징을 찾습니다.
  4. 이름 붙이기 — «우유를 먹이는 무리 = 포유류?», «깃털 있는 무리 = 조류?»
  5. File 에서 type 을 다시 target 으로 돌리고 Data Table 에서 Cluster 열과 type 을 나란히 — 정답 없이도 얼마나 맞게 묶었나?

확인잘못 묶인 동물은? 왜 헷갈렸을까(예: 박쥐 · 오리너구리 · 돌고래)?

7우리 팀 데이터 불러오기프로젝트 ③ 첫 10분
  1. File 에서 우리 CSV 를 엽니다. 한글이 깨지면 Encoding 을 UTF-8 ↔ 한국어(CP949) 로 바꿔 봅니다.
  2. 아래 표에서 열마다 Role — 맞힐 열 target · 쓰지 않을 열(번호 · 이름 · 날짜) skip · 나머지 feature. Type 이 숫자(numeric)인지 범주(categorical)인지도 확인.
  3. Preprocess — Impute(빈칸 채우기) · Normalize(kNN · SVM · 신경망 · k-평균이면).
  4. Data Sampler 70% / 30% 로 나누고, Test and Score 에서 Test on test data.
  5. 정리한 데이터는 Save Data 로 저장 — 수행평가 ② 코랩 노트북에서 같은 파일을 씁니다.
