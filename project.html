  4. 성공 기준을 넘었나

  1. 어느 숫자를 보나 — Test and Score를 «Test on test data»로 두고 우리 모델 줄과 Constant 줄을 봐요. 분류는 CA(정확도) · Recall(재현율). 위쪽 «Target class»를 놓치면 안 되는 답(예: «나쁨» · «피싱»)으로 바꾸면 그 답의 재현율이 나와요. 예측(회귀)은 MAE · RMSE · R2.
  2. 내 말로 — «정확도 0.82 = 테스트 100개 중 82개를 맞힘» · «재현율 0.70 = 실제 «나쁨» 10개 중 7개를 찾아냄» · «MAE 15 = 평균 15만큼 빗나감».
  3. 기준선과 비교 — Constant는 아무것도 배우지 않고 가장 많은 답만 찍는 모델이에요(회귀는 평균만). «우리 0.82 vs Constant 0.63 → 0.19 더 나음». 둘이 비슷하면 모델이 거의 못 배운 거예요.

  5. 성공 기준 판정 — 계획서 목표 숫자와 나란히: «목표 0.90 · 결과 0.898 → 아깝게 미달».
점수가 1.0이나 0.99면 의심부터 — 정답을 만든 열(예: 등급을 만든 BOD)이 입력에 남아 있거나, Test on train data로 잰 거예요.

네 칸 예시

  1. 가설 — «습도» 열을 빼면 «나쁨» 재현율이 오를 것이다, 왜냐하면 습도는 등급과 관계가 적어 모델을 헷갈리게 하니까.
  2. 조작 — Select Columns에서 «습도»만 뺌 (모델 · 나누기는 그대로)
  3. 결과 — «나쁨» 재현율 0.70 → 0.74 (둘 다 Test on test data)
  4. 해석 — 왜 올랐(그대로였)을까 + 편향 하나(확증 · 선택 · 역사적 · 생존자): «데이터가 한 지역뿐이라 다른 지역에선 다를 수 있음(선택 편향)»
🎯 요소 ③ 25점은 «바꾼 것이 그 편향을 겨냥»해야 해요 — 위 예시(습도 빼기 + 편향은 해석에서만)는 20점 쪽이에요. 25점 예: «한 지역뿐(선택 편향) → 지역 · 측정소 열을 빼 지역에 기대는 것을 줄여 봄» · «과거 기록(역사적 편향) → 부모 학력 열을 빼 봄».
✓ 효과가 없어도 좋은 실험 — «그대로였다 → 습도는 영향이 작다»도 결론이에요.
✗ 두 개를 한꺼번에 · 전과 후를 다른 지표로 · 돌려 보지 않은 숫자
📚 예시 더 보기 분류 · 예측 · 나빠진 결과 — 숫자는 예시예요

① 분류 · 편향을 겨냥한 열 빼기 (25점 쪽) — 약수터 수질 «부적합» 찾기

  1. 가설 — 측정 지점이 몇 지역에 몰려 있어(선택 편향) 모델이 «어느 지역이냐»에 기댈 것이다. «지점» 열을 빼면 수질 값 자체로 판단해 «부적합» 재현율이 오를 것이다.
  2. 조작 — 입력 열에서 «지점» 하나만 뺌 (모델 · 나누기는 그대로)
  3. 결과 — «부적합» 재현율 0.75 → 0.85 (실제 부적합 20곳 중 15곳 → 17곳)
  4. 해석 — 지역에 기대던 판단이 줄었어요. 놓쳐서 사람이 마실 뻔한 물이 2곳 줄어요. 다만 다른 지역 데이터로는 아직 확인 못 했어요.

② 예측 · 설정 하나 · 결과가 나빠진 경우 — kNN 이웃 수

  1. 가설 — 이웃을 5 → 15로 늘리면 튀는 값의 영향이 줄어 MAE가 작아질 것이다.
  2. 조작 — n_neighbors=5 → 15 만 바꿈
  3. 결과 — MAE 116명 → 124명 (나빠짐 · 작을수록 좋은 지표)
  4. 해석 — 너무 먼 이웃까지 평균을 내서 실제 차이가 묻혔어요. 우리 데이터엔 5가 더 맞아요. 평일 자료가 대부분이라 주말엔 더 틀릴 수 있어요(선택 편향).

👉 나빠지거나 그대로여도 좋은 결과예요 — 실제로 잰 숫자와 «왜»로 점수를 받아요. 숫자를 좋게 바꿔 적으면 안 돼요.

③ 모델 바꾸기 — Tree → Random Forest

  1. 가설 — 나무 여러 그루가 함께 판단하면 한 나무가 놓친 «미달»을 더 찾을 것이다.
  2. 조작 — 모델_이름 = 'Tree' → 'Random Forest' (입력 열 · 나누기는 그대로)
  3. 결과 — 정확도 0.86 → 0.86 (그대로) · «미달» 재현율 0.40 → 0.55
  4. 해석 — 정확도는 그대로지만 놓치면 안 되는 «미달»을 더 찾았어요. 그래서 재현율로 판단해요. «미달»이 적은 데이터라 정확도만 보면 속기 쉬워요.

끝나면 3절을 원래대로 되돌리고 «모두 실행» — 3 · 4 · 9절 숫자가 내 최종 숫자예요.

🎯 요소 ③ 25점은 «바꾼 것이 그 편향을 겨냥»해야 해요 — 위 예시(습도 빼기 + 편향은 해석에서만)는 20점 쪽이에요. 25점 예: «한 지역뿐(선택 편향) → 지역 · 측정소 열을 빼 지역에 기대는 것을 줄여 봄» · «과거 기록(역사적 편향) → 부모 학력 열을 빼 봄».
✓ 효과가 없어도 좋은 실험 — «그대로였다 → 습도는 영향이 작다»도 결론이에요.
✗ 두 개를 한꺼번에 · 전과 후를 다른 지표로 · 돌려 보지 않은 숫자
📚 예시 더 보기 분류 · 예측 · 나빠진 결과 — 숫자는 예시예요

① 분류 · 편향을 겨냥한 열 빼기 (25점 쪽) — 약수터 수질 «부적합» 찾기

  1. 가설 — 측정 지점이 몇 지역에 몰려 있어(선택 편향) 모델이 «어느 지역이냐»에 기댈 것이다. «지점» 열을 빼면 수질 값 자체로 판단해 «부적합» 재현율이 오를 것이다.
  2. 조작 — 입력 열에서 «지점» 하나만 뺌 (모델 · 나누기는 그대로)
  3. 결과 — «부적합» 재현율 0.75 → 0.85 (실제 부적합 20곳 중 15곳 → 17곳)
  4. 해석 — 지역에 기대던 판단이 줄었어요. 놓쳐서 사람이 마실 뻔한 물이 2곳 줄어요. 다만 다른 지역 데이터로는 아직 확인 못 했어요.

② 예측 · 설정 하나 · 결과가 나빠진 경우 — kNN 이웃 수

  1. 가설 — 이웃을 5 → 15로 늘리면 튀는 값의 영향이 줄어 MAE가 작아질 것이다.
  2. 조작 — n_neighbors=5 → 15 만 바꿈
  3. 결과 — MAE 116명 → 124명 (나빠짐 · 작을수록 좋은 지표)
  4. 해석 — 너무 먼 이웃까지 평균을 내서 실제 차이가 묻혔어요. 우리 데이터엔 5가 더 맞아요. 평일 자료가 대부분이라 주말엔 더 틀릴 수 있어요(선택 편향).

👉 나빠지거나 그대로여도 좋은 결과예요 — 실제로 잰 숫자와 «왜»로 점수를 받아요. 숫자를 좋게 바꿔 적으면 안 돼요.

③ 모델 바꾸기 — Tree → Random Forest

  1. 가설 — 나무 여러 그루가 함께 판단하면 한 나무가 놓친 «미달»을 더 찾을 것이다.
  2. 조작 — 모델_이름 = 'Tree' → 'Random Forest' (입력 열 · 나누기는 그대로)
  3. 결과 — 정확도 0.86 → 0.86 (그대로) · «미달» 재현율 0.40 → 0.55
  4. 해석 — 정확도는 그대로지만 놓치면 안 되는 «미달»을 더 찾았어요. 그래서 재현율로 판단해요. «미달»이 적은 데이터라 정확도만 보면 속기 쉬워요.

네 칸 예시

  1. 가설 — «습도» 열을 빼면 «나쁨» 재현율이 오를 것이다, 왜냐하면 습도는 등급과 관계가 적어 모델을 헷갈리게 하니까.
  2. 조작 — Select Columns에서 «습도»만 뺌 (모델 · 나누기는 그대로)
  3. 결과 — «나쁨» 재현율 0.70 → 0.74 (둘 다 Test on test data)
  4. 해석 — 왜 올랐(그대로였)을까 + 편향 하나(확증 · 선택 · 역사적 · 생존자): «데이터가 한 지역뿐이라 다른 지역에선 다를 수 있음(선택 편향)»
🎯 요소 ③ 25점은 «바꾼 것이 그 편향을 겨냥»해야 해요 — 위 예시(습도 빼기 + 편향은 해석에서만)는 20점 쪽이에요. 25점 예: «한 지역뿐(선택 편향) → 지역 · 측정소 열을 빼 지역에 기대는 것을 줄여 봄» · «과거 기록(역사적 편향) → 부모 학력 열을 빼 봄».
✓ 효과가 없어도 좋은 실험 — «그대로였다 → 습도는 영향이 작다»도 결론이에요.

① 분류 · 편향을 겨냥한 열 빼기 (25점 쪽) — 약수터 수질 «부적합» 찾기

  1. 가설 — 측정 지점이 몇 지역에 몰려 있어(선택 편향) 모델이 «어느 지역이냐»에 기댈 것이다. «지점» 열을 빼면 수질 값 자체로 판단해 «부적합» 재현율이 오를 것이다.
  2. 조작 — 입력 열에서 «지점» 하나만 뺌 (모델 · 나누기는 그대로)
  3. 결과 — «부적합» 재현율 0.75 → 0.85 (실제 부적합 20곳 중 15곳 → 17곳)
  4. 해석 — 지역에 기대던 판단이 줄었어요. 놓쳐서 사람이 마실 뻔한 물이 2곳 줄어요. 다만 다른 지역 데이터로는 아직 확인 못 했어요.

② 예측 · 설정 하나 · 결과가 나빠진 경우 — kNN 이웃 수

  1. 가설 — 이웃을 5 → 15로 늘리면 튀는 값의 영향이 줄어 MAE가 작아질 것이다.
  2. 조작 — n_neighbors=5 → 15 만 바꿈
  3. 결과 — MAE 116명 → 124명 (나빠짐 · 작을수록 좋은 지표)
  4. 해석 — 너무 먼 이웃까지 평균을 내서 실제 차이가 묻혔어요. 우리 데이터엔 5가 더 맞아요. 평일 자료가 대부분이라 주말엔 더 틀릴 수 있어요(선택 편향).

👉 나빠지거나 그대로여도 좋은 결과예요 — 실제로 잰 숫자와 «왜»로 점수를 받아요. 숫자를 좋게 바꿔 적으면 안 돼요.

③ 모델 바꾸기 — Tree → Random Forest

  1. 가설 — 나무 여러 그루가 함께 판단하면 한 나무가 놓친 «미달»을 더 찾을 것이다.
  2. 조작 — 모델_이름 = 'Tree' → 'Random Forest' (입력 열 · 나누기는 그대로)
  3. 결과 — 정확도 0.86 → 0.86 (그대로) · «미달» 재현율 0.40 → 0.55
  4. 해석 — 정확도는 그대로지만 놓치면 안 되는 «미달»을 더 찾았어요. 그래서 재현율로 판단해요. «미달»이 적은 데이터라 정확도만 보면 속기 쉬워요.
