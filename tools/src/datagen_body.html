주제만 넣으면 주제에 맞는 열을 추천하고, 관계가 숨어 있는 연습용 가상 데이터를 만들어 줍니다. 결측치 · 이상치 · 중복 · 오탈자 · 단위 오류 · 날짜 형식 · 불균형을 일부러 넣어 전처리 실습을 하고, CSV · JSON · Excel로 받아 코랩 · 오렌지3에서 바로 씁니다. 데이터 번호가 같으면 반 전체가 똑같은 데이터로 시작합니다.

이용 방법 보기
  1. 기본 설정 — 대상 학년 · 주제 · 열 복잡도 · 관측치 수를 고릅니다. 템플릿을 누르면 한 번에 채워집니다.
  2. ✦ 컬럼 추천을 누르거나 주제 칸에서 Enter. 연관 키워드를 누르면 그 주제로 바꿔 다시 추천합니다.
  3. 컬럼 편집 — 이름 · 타입(숫자 · 범주 · 날짜 · 참/거짓)을 고치거나 직접 추가합니다. 모델 연습을 하려면 정답 열을 하나 고르세요.
  4. 데이터 품질 옵션 — 노이즈 · 결측치 등 수업 목적에 맞게 켜고 세기를 고릅니다.
  5. 데이터셋 생성 시작 → CSV · JSON · Excel로 내려받고, 📊 데이터 통계와 그래프로 확인합니다.

어떻게 만들까? 인터넷 AI를 부르지 않고, 이 쪽 안에 든 주제 사전(66개)과 열 사전(190여 가지 · 낱말 600여 개)으로 주제에 맞는 열을 고릅니다 — 그래서 학교 와이파이에서도, 로그인 없이도 됩니다. 사전에 없는 열 이름은 «시간 · 점수 · 만족도 · 여부 · 횟수 · 비율 · 금액» 같은 끝말로 값의 범위를 짐작합니다. 값은 숨은 요인 하나로 서로 엮어 만들기 때문에 상관 · 예측 · 분류가 실제로 됩니다. 모든 값은 만든 값(가상 데이터)이니 결론을 실제 사실처럼 쓰지 마세요.
