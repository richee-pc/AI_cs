📈 그래프 만들기

코랩이 안 될 때 쓰는 대신 화면이에요. 로그인 없이 우리 CSV를 올리면 코랩 21과 같은 그래프 · 상관계수 r · 표본 수 n이 나와요. 파일은 내 컴퓨터 안에서만 읽고 어디에도 보내지 않아요.

① 파일 올리기

📁 «우리데이터_전처리.csv»를 여기에 끌어다 놓거나 눌러서 고르기
모둠 데이터 폴더에서 먼저 내 컴퓨터로 내려받아요 · 엑셀 파일이면 «다른 이름으로 저장 → CSV», 구글 시트면 «파일 → 다운로드 → CSV»

② 설정 — 코랩 21의 ✏️ 칸과 같아요

💡 고르기 어려우면 전부 보기로 다 그려 보고, 우리 가설을 가장 정직하게 보여 주는 것을 하나 골라 캡처해요. 1차시에 맡은 그래프부터!

③ 1차 해석 — AI 없이 먼저 (슬라이드 «나의 시각화와 1차 해석»)

그래프 자가 점검 — ☐ 세로축을 잘라 부풀리지 않았다 ☐ n을 적었다 ☐ 상관을 원인과 결과로 말하지 않았다 ☐ 불리한 데이터도 남겼다
  • 내가 고른 그래프와 이유: «____ 그래프를 고른 까닭은 ____ 을(를) 보이기 위해서다.»
  • 그래프에서 직접 본 것: «____ 가 높을수록 ____ 는 ____ (r = ____, n = ____).»
  • 나의 1차 해석: «그래서 ____ 라고 생각한다.»
  • 이 데이터가 말하지 않는 것: «____ 때문이라고는 말할 수 없다(____ 의 영향 · ____ 기간/지역만).»

캡처: 그래프 아래 📋 그림 복사 → 슬라이드에서 Ctrl+V. 안 되면 💾 그림 저장 후 «삽입 → 이미지», 또는 Win+Shift+S.
